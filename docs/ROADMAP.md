# Roadmap - Portafolio Profesional Django

## Objetivo General

Desarrollar un portafolio profesional que sirva como evidencia técnica para reclutadores, clientes y entrevistas, manteniendo una arquitectura limpia, escalable y fácil de administrar.

---

# Sprint 1 - Infraestructura

Estado: 🟡 En progreso

Objetivo:

- Compatibilizar el almacenamiento entre distintos proveedores.
- Mantener Cloudinary como opción.
- Permitir almacenamiento local.
- Eliminar dependencias innecesarias del hosting.

Tareas:

- [ ] Cloudinary opcional.
- [ ] FileSystemStorage compatible.
- [ ] PythonAnywhere funcionando.
- [ ] Render funcionando.
- [ ] Documentación actualizada.
- [ ] Commit.
